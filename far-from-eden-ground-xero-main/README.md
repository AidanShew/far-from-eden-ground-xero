# Far From Eden: Ground Xero
## Camapign
Ground Xero features only the first mission titled "Ground Xero". The decision to split the game into 4 parts was made to have players test the game as it's being developed, and to release the game faster than it would have. Expect the final game, simply titled "Far From Eden", to include a 4-part campaign story mode.

##### Campaign as of June 9th 2026
Ground Xero is in an unfinished state as many new path tracing for bullets and enemies are actively being developed and tested. Launching Campaign right now may result in the game crashing.

## Firefight
While the focus of Ground Xero is the first mission alone, an endless arcade-style horde mode is also being developed for the final release of the game. Although this mode is in development, the Campaign takes higher priority.

##### Firefight as of June 9th 2026
Firefight has not been tested recently and may result in a crash before getting very far. Some mechanics are still functional such as stat tracking however anything past the first wave is unstable.

## Playground
This is where all of the newest developments are being tested and developed. Enemies in Playground will change periodically as I am finalizing and testing different gameplay systems. This mode will not be featured in the final release.

##### Playground as of June 9th 2026
Playground currently hosts the new "Treclops" boss. This boss features multiple different attack modes and phases. This boss is meant to test the player's reaction speed and ability to adapt to new situations.


## Update on Development
Everything is progressing smoothly, Far From Eden: Ground Xero is still on track to be released in early August! I wanted to release this project before the end of summerS plitting the game into parts has helped me realistically attain the release goal, especially while juggling work, gym, and having any sort of social life. As of right now, programming is nearly complete with the final boss nearing end of development. After programming is finished, art will be the new challenge as nearly everything uses a temporary asset. I'm looking forward towards optimziation and cleaning up the code as I notice many systems, scripts, objects, etc. that could be simplified or just removed entirely.
